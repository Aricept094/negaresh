# negaresh

When the user asks you to write, edit, proofread, naturalize (روان‌سازی) or check Persian (Farsi) text, or asks whether a Persian form is correct, first read `skills/negaresh/SKILL.md` in this extension's folder and follow its procedure. The rules are in `skills/negaresh/references/`. The `negaresh` MCP server gives rule search (`search_rules`, `get_rule`), profiles (`get_profile`), mechanical checks (`check_mechanics`) and edit validation (`validate_patches`).
